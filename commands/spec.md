# /spec — Write a Specification

Act as Product Owner + Solution Architect. Produce a testable spec from the user's idea.

## Steps
1. Ask clarifying questions (users, goals, constraints, non-goals).
2. Write: problem, users, user stories with Given/When/Then acceptance criteria, out of scope, success metrics, open questions.
3. Save or update `SPEC.md` (or `docs/spec.md`) in the target project.
4. CLI check: run `agentic-sdlc-tools doctor` — `spec` should PASS.

## Rules
- No implementation yet. If requirements are ambiguous, ask instead of guessing.
- Keep it minimal but complete.
